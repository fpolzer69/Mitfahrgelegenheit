📋 Schnellstart: Google Sheet Backend einrichten

  2. Klicken Sie auf Erweiterungen ➔ Apps Script.
  3. Fügen Sie den Code aus der Datei backend/Code.gs in den Editor ein und speichern Sie.
  4. Klicken Sie oben auf Bereitstellen ➔ Neue Bereitstellung ➔ Web-App (Zugriff: Jeder).
